Jak powtórzyć MEDA 1.0?

MEDA 1.0 zaliczona: zgłoszono udane wykonanie prób według instrukcji. Dziennik IA–MEDA–OBS/002/2026 zawiera zbiorczy meldunek operatora; tempo i dokładne godziny nie zostały podane. Emisja odbyła się lokalnie, bez weryfikacji odbioru.

1. Podłącz wcześniej uruchomioną płytkę Pico 2 WH do komputera przez micro-USB. Otwórz Thonny, wybierz interpreter MicroPython (Raspberry Pi Pico) i port płytki. Firmware z poprzedniego udanego testu MEDA 0.1 nie wymaga ponownego wgrywania.

2. Pobierz i otwórz plik meda_1_0_morse.py. Wybierz uruchomienie F5. W dolnej konsoli Shell program pokaże wiadomość, jej kod Morse’a i napis MEDA>.

3. Dla wyraźniejszego migania wpisz w Shell TEMPO 8, zatwierdź Enterem, następnie wpisz START i obserwuj diodę. Na koniec program zapyta, czy transmisja zadziałała. Wpisz T tylko wtedy, gdy rzeczywiście widziałeś prawidłowe miganie.

4. Powtórz komendę START, aż będziesz mógł potwierdzić łącznie trzy prawidłowe emisje. Komenda STATUS pokazuje liczniki. STOP kończy sesję między emisjami, a Ctrl+C służy do przerwania transmisji w trakcie.

5. Dopiero po próbie zgłoś datę, liczbę emisji i wynik do aktualizacji dziennika IA–MEDA–OBS/002/2026. Komunikat o nadaniu przez program nie jest niezależnym dowodem dotarcia sygnału do odbiornika.

Znaczenie eksperymentu

MEDA 1.0 jest lokalnym demonstratorem komunikacji optycznej. Bez fotoczujnika nie prowadzi automatycznej weryfikacji odbioru. Nie jest to transmisja do Galaktyki Andromedy. Program używa wyłącznie wbudowanej diody; dodatkowych części ani laserów nie potrzeba.
